# Critères de réussite — WaveDevSecOps

Les critères « collègues » sont vérifiés par des collègues s'ils sont disponibles, sinon par Anaël.

## v0.1, socle git

| Critère | Mesure |
|---|---|
| Anaël finit les scénarios sans indice | Zéro indice utilisé par scénario, quiz ≥ 80 % du premier coup (CAP-9) |
| Installation autonome | 2 collègues installent seuls, sans droits admin, en moins de 10 min (chronomètre) |
| Socle tenu en une heure | En 1 h ou moins, ils finissent branche → PR → conflit → récupération |
| Compréhension du mode B | Ils expliquent ce qu'un agent a fait sur le dépôt |
