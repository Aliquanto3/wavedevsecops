# WaveDevSecOps v0.1.0 : le socle git

Première version testable. Elle livre le socle git, hors ligne, en deux modes. Elle n'envoie aucune
télémétrie et ne fait aucun appel réseau, sauf l'exécution facultative du code LLM.

## Contenu de la v0.1

- **Installation sans droits administrateur** (Epic 1) : `install.ps1` (Windows) et `install.sh`
  (macOS, Linux) ; uv, git si besoin, gitleaks, préchargement du cache pour travailler ensuite
  hors ligne ; diagnostic des outils du poste.
- **Un vrai dépôt git, un dépôt distant local et un GitHub simulé** (Epics 2 à 4) : bac à sable,
  terminal, vues synchronisées (graphe des commits, index, code), PR, revue et merge simulés,
  indices, solution, bouton Recommencer, reprise du dernier scénario.
- **Mode A, vous tapez** : `add-commit`, `push-pull`, `branche`, `pr-merge`, `conflit`, `stash`,
  `rebase`, `recuperation`, plus un bac à sable libre.
- **Mode B, vous lisez ce qu'un agent a fait** (Epic 5) : `add-commit`, `push-pull`, `stash` (stash
  oublié) et `rebase` (rebase laissé en conflit), avec quiz où la mauvaise commande est exécutée
  pour de vrai, expliquée, puis annulée.
- **Deux parcours** (Epic 6) : parcours LLM et parcours sans IA ; rapport de progression exportable ;
  exécution facultative du code d'exercice du parcours LLM, sur confirmation.

## Installer cette version

Les commandes du README installent la tête de `main`. Pour installer exactement la v0.1.0, posez
`WDS_INSTALL_REF=v0.1.0` et téléchargez l'installeur de la même étiquette :

```sh
curl -fsSL https://raw.githubusercontent.com/Aliquanto3/wavedevsecops/v0.1.0/install.sh | WDS_INSTALL_REF=v0.1.0 sh
```

```powershell
$env:WDS_INSTALL_REF = 'v0.1.0'
```

puis la commande Windows du README, en remplaçant `/main/install.ps1` par `/v0.1.0/install.ps1`.

## Limites connues

- **Vérifications sur poste réel en attente** : l'installation sous Windows non administrateur
  derrière un proxy, l'installation sous macOS et Linux sur un poste personnel, l'exécution LLM avec
  un vrai Ollama. Les tests les simulent ; la recette ci-dessous les couvre en partie.
- **Encart « Ce qui l'aurait bloqué » absent des scénarios B** : après
  lecture du travail de l'agent, la vue ne dit pas ce qui l'aurait empêché de se tromper.
- **Comportements susceptibles d'évoluer** : `rm -rf *` est accepté dans le terminal du bac à sable,
  comme dans un vrai shell ; sous Windows, un fichier sans éditeur associé s'ouvre dans le Bloc-notes ;
  la lecture d'un scénario B est plafonnée à 15 minutes ; « Ouvrir une PR » est masqué pour une
  branche déjà contenue dans `main` ; une approbation de PR reste valable après un nouveau push.
- Le code d'exercice du parcours LLM suppose Ollama sur `127.0.0.1:11434` ; sans lui, l'exécution
  échoue avec un message, le reste fonctionne.
